# Oscillator Configuration

## Oscillator volume control

As a website visitor, I want to adjust the volume of the oscillator in real-time, allowing me to fine-tune its level in relation to other instruments in the mix.

**Acceptance Criteria:**
1. A user-accessible form should be present on the website to modify the oscillator parameters.
2. The form should include a range input (slider) that allows the user to adjust the volume of the oscillator.

## Oscillator Wave Shape Control

As a website visitor, I want to adjust the oscillator's wave shape in real-time, enabling me to modify the tone according to my preferences.

**Acceptance Criteria:**
1. The oscillator parameters form should include a dropdown menu that allows the user to select different wave shapes for the oscillator.
